扫描流程

  1. 代码解析

    提取函数、调用关系与可达入口。

  2. 上下文增强

    补充项目背景与代码安全语义。

  3. 漏洞分析

    由模型识别风险与潜在攻击路径。

  4. 复核与动态测试

    按选项模拟攻击、运行隔离测试。

  5. 结果报告

    查看中文摘要、风险详情和披露材料。

结果需要人工复核模型发现不等于已确认漏洞。请结合证据、适用前提和动态测试结果判断，避免直接用于生产环境。
